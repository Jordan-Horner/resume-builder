# Exports

Use this directory for finished files that are ready to upload or share.

Resume PDFs are organized under `resumes/<target>/`. The target folder helps you
identify each tailored version, while the PDF uses a neutral
`<candidate-name>-Resume.pdf` filename so the employer does not see another
company's name.

These PDFs are generated copies, not editable sources. Make resume changes under
`resumes/`, then run the preview and mint workflow again.
