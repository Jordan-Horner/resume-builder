# Application History

Files in this directory preserve private application records, append-only status
events, and submitted application answers. They are application artifacts, not
career evidence. Never use an application answer to establish a career fact.

Use `resume-builder application` to preview and write these records. Do not edit
event history in place; corrections should supersede an earlier event.

`resume-builder gmail` may create or link an application after a high-confidence
application confirmation. Automated events contain only structured provenance,
an opaque external reference, and classifier metadata. Gmail message content and
message IDs are never stored here.
